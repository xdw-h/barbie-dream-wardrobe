# 梦想衣橱

经典金发时尚娃娃换装小游戏，支持48套服装、6种鞋色、6件配饰、7种服装风格筛选、随机搭配、撤销、本地收藏与 PNG 下载。新增20款经典造型、10款电影造型。

纯静态 HTML/CSS/JavaScript。直接打开 `index.html`，或通过静态服务托管。首屏仅内嵌默认娃娃完整图片和48张缩略图，素材脚本约668 KB；其余完整图片按需从 `assets/packages/` 的本地脚本包读取。无需外部字体服务。复制游戏时必须携带该目录；收藏仍保存在当前浏览器。

## GitHub Pages

在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `master`，目录选择 `/ (root)`，保存后等待部署完成。

## 素材

娃娃和服装使用 AI 生成，以经典芭比实体娃娃外观为参考，并非官方商品照片或官方应用。收藏仅保存在访问者当前浏览器。
