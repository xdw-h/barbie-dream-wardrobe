# 梦想衣橱

经典金发时尚娃娃换装小游戏，支持十八套服装、六种鞋色、六件配饰、五种服装风格筛选、随机搭配、撤销、本地收藏与 PNG 下载。

纯静态 HTML/CSS/JavaScript。直接打开 `index.html`，或通过 GitHub Pages 托管。所有运行图片内嵌于 `assets-data.js`，不依赖后台。

## GitHub Pages

在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `master`，目录选择 `/ (root)`，保存后等待部署完成。

## 素材

娃娃和服装使用 AI 生成，以经典芭比实体娃娃外观为参考，并非官方商品照片或官方应用。收藏仅保存在访问者当前浏览器。
